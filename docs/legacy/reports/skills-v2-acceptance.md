1. 私有仓库首次被付款/支出上限拦截；用户明确批准转为公开后Actions恢复。发布前检查已提交历史的凭据模式，私密状态和本机配置未加入Git。
2. 初次回归发现创建时间戳比较、Windows短路径、缺少使用文件等问题，修正后两端各93项通过。
3. Claude测试时钟曾停留在旧日期；改用Asia/Shanghai当前日期，并验证冻结的具体任务日期。
4. CLI入口曾被解释为库根或执行器根；补充相对路径以SKILL.md目录为准，安装入口读取本机连接文件。保留该失败记录。

7. 同一run的重跑可能留下同名旧artifact。普通整批下载取得过旧MCP失败报告，安装前校验及时停止；随后按确切artifact ID`11659004906`下载最后通过记录，并核对提交、buildRun、模型和passed。其他通过记录对应artifact ID分别为CLI执行`11660465225`、CLI取消`11660480783`、MCP取消`11660134272`。
