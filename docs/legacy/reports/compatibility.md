# v2 兼容与验收边界

标准技能包含 name、description、compatibility、相对脚本与所需参考资料。无厂商会话解析、模型绑定、审批关键词或 supportedProviders 限制；执行使用当前宿主的会话确认和统一 CLI/MCP。

v2 新增不可变预览指纹、历史方案只读、拒绝错范围和篡改、相关输入失效/无关输入不失效、无厂商日志环境、标准输入 JSON、单个技能资源完整性、迁移安装目录、逐资源冲突守卫、更新幂等与自定义发现目录。
