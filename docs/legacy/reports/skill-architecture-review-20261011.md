# Cosmos 技能架构复审（2026-10-11）

结论：v2 执行器的准备、不可变预览和批准后执行边界保留；缺陷位于技能编排及验收。旧安装格式基本符合 Agent Skills，但按需加载、入口确定性和实际行为验收没有落实充分。先前“四次 Cosmos 调用”通过不能证明整个模型流程精简或响应快。

## 实际证据

本机 Claudian 创建单任务的会话：规划 178.372 秒，六次宿主工具调用及交接 6.709 秒，七个完成的模型响应；plan 所在终端命令约 0.5 秒。已注入技能全文仍重复读取，PowerShell 未指定 UTF-8 返回乱码，继而两次扫目录并读取通用参考、连接和完整调用契约。批准后 118.138 秒，执行及复检交接合计 1.836 秒。私有原始记录保存在库外 state，不提交会话或用户资料。

工具外耗时主导；日志尚不能进一步区分上游排队、模型推理或传输等待。实际会话为 gpt-5.6-luna/xhigh；按用户原约束，Actions 评估仍固定 gpt-6-luna/xhigh，不借切换模型证明修复。

## 已确认缺陷与修正

| 缺陷 | 修正 |
| --- | --- |
| 构建阶段在每份正文追加完整调用契约，重复已有流程 | 打包保持源 SKILL.md 原样；完整机器契约留在 scripts/invocation.json 和按需 --help |
| 已知创建仍可先查目录、连接及参考 | 说明材料齐全直接 prepare；只在定位、补资料或明确报错时定向查询；入口自行解析绑定 |
| 已注入全文仍重复读取，Windows 文本读取乱码 | 已加载则沿用；必要文本读取显式 UTF-8；参数继续使用经过校验的库外 UTF-8 JSON |
| 机械保存与调用增加模型往返 | 允许同一终端调用内依次序列化、验证、运行，失败即停止 |
| 测试系统提示预先教模型 prepare/plan、字段和摘要路径 | 去掉额外流程提示，只保留日期、时区及隔离环境信息；从技能发现或原始技能注入开始 |
| 仅统计四次业务服务调用 | 同时记录宿主工具、重复读取/扫描、独立模型响应、各阶段耗时；无计量标未验证 |
| 性能门槛不包含实际等待时间 | 增加规划/批准后耗时及响应回合预算；服务调用合格而流程慢仍判失败 |

## 验收边界

全部构建和自动测试在 GitHub Actions，使用同一候选产物。本机只做安装核验、发现和只读检查，不创建测试业务笔记。保留十个技能、v2 审批、历史计划/回执/锁和原绑定；不改变账户、模型、权限、插件、规则或模板。

材料齐全单任务规划预算 90 秒、单篇完整游记 150 秒，批准后 60 秒；隐式发现最多四个完成模型响应，已注入技能的规划最多三个，批准后最多三个。额外无关探索必须为零。响应数来自宿主原生响应 ID，表示完成回合，不等同于 HTTP 尝试次数或网关账单。
