# 实施计划与执行记录

依据 approved-design.md 实施。知识库只读；开发与状态存库外。不使用子代理，不操控桌面，不实际上传 Amytis 内容。

1. 建立私有工程、来源指纹和外置快照。十个技能按自然语言发现，公共规则索引按需读取。
2. 实现外置 CLI／stdio MCP、实时规则读取、真实关系校验、审批计划、冲突检查、串行执行和日志。执行调用现有引擎或插件 API。
3. 集成实体、生命周期、TaskNotes、文件与 Amytis。周期使用已验证的原生入口；不支持的任意日期调用明确停止。
4. 通过 GitHub Actions 生成锁文件，再固定依赖；所有语法检查、构建、自动测试和安装包检查均在 Actions 执行，不在本机运行。
5. 下载该次 CI 产物并核验 SHA256，按非覆盖策略安装用户级技能入口；不改 Claudian、MCP 或库内配置。交付命令调用与可选 MCP 配置示例。
6. 全库前后指纹对比，记录通过、受限和运行时待验证项。缺少真实 CLI、代理调用或界面验证时不标为全部验收完成。

仓库默认私有，避免公开项目契约。CI 只使用自有规则、引擎和脱敏合成笔记；不上传用户笔记、插件 data.json、凭据和私人照片。

CLI 传输未通过实机门槛前，技能可提供方案；写工具在调用时报告缺少能力。不会自行安装桥接插件或直接写 YAML 代替业务服务。
